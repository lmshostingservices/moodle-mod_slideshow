# mod_slideshow

## Summary

Image slideshow activity with PowerPoint import, AI voiceover narration (52 languages, Google Chirp 3 HD), per-slide text editor, OCR text extraction, drag-and-drop reordering, video slides (YouTube URL, direct URL, or uploaded MP4/WebM), poster image slides, watch-time gating on video slides, position selector, completion tracking, and credit-based billing via Central Config.

## Description

Image slideshow activity with PowerPoint import, AI voiceover narration (52 languages, Google Chirp 3 HD), per-slide text editor, OCR text extraction, drag-and-drop reordering, video slides (YouTube URL, direct URL, or uploaded MP4/WebM), poster image slides, watch-time gating on video slides, position selector, completion tracking, and credit-based billing via Central Config. Perfect for induction walkthroughs, site tours, video-based training, and mixed-media learning sequences.
